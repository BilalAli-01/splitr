# Splitr

**[splitr-one-kappa.vercel.app](https://splitr-one-kappa.vercel.app)**

A mobile-first web app for splitting group event costs in Australia. Create an event, share the link, and everyone knows exactly how much to send via PayID — no payment processing, no app download needed.

## How it works

1. **Create an account** and set up your event with a total cost and number of spots
2. **Share the join link** with your group
3. **Participants join** and see exactly how much they owe, with PayID details to pay instantly
4. **Track payments** from your organiser dashboard — mark people as paid as money comes in
5. **Close the event** when done — it stays on record as a read-only summary

## Features

- Cost automatically split per person — participants see a clear amount to pay
- Participants can add multiple names in one go (e.g. bringing a friend)
- Configurable leave restrictions — lock headcounts before the event
- Organiser dashboard to mark paid/unpaid, remove participants, and edit details
- All your events in one place — active and closed
- Works great on mobile
